# 🚀 Curso de Angular

Repositório dedicado aos estudos, exercícios práticos e projetos desenvolvidos durante o curso de **Angular**. O objetivo deste espaço é documentar minha evolução no framework e servir como material de consulta rápida.

---

## 🛠️ Tecnologias Utilizadas

* **Angular** (v17+ / Standalone Components)
* **TypeScript**
* **HTML5 & CSS3 / SCSS**
* **RxJS** (Programação Reativa)
* **Node.js & npm**

---

## 📚 Conteúdo Estudado

- [x] **Fundamentos:** Arquitetura do Angular, CLI, Componentes e Módulos.
- [x] **Data Binding & Diretivas:** Interpolação, Property/Event Binding, Two-way Binding, `@if`, `@for` e diretivas estruturais.
- [ ] **Comunicação entre Componentes:** `@Input()`, `@Output()`, `EventEmitter` e Signals.
- [ ] **Serviços e Injeção de Dependência:** Criação de services, `HttpClient` e consumo de APIs REST.
- [ ] **Roteamento:** Configuração de rotas, parâmetros de URL, Lazy Loading e Route Guards.
- [ ] **Formulários:** Template-driven Forms e Reactive Forms (validações).

## ⚙️ Como Executar os Projetos Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Acesse a pasta do projeto desejado:**
   ```bash
   cd nome-do-repositorio/nome-do-projeto
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   ```

4. **Inicie o servidor de desenvolvimento:**
   ```bash
   ng serve
   ```
   Abra o navegador e acesse `http://localhost:4200/`.
